# _example

Flat 60 x 40 x 6 mm mounting plate with four M3 clearance holes (3.4 mm), 5 mm in
from each edge, and 2 mm fillets on the vertical corners and top edge.

- **Source:** original (designed here)
- **Licence:** n/a (own design)
- **Build:** `just build _example` -> `out/_example.3mf`

## Print settings
- Orientation: flat on the bed, as modelled
- Material: PLA or PETG
- Layer height 0.2 mm, 3 walls, 15-20 % infill, no supports
