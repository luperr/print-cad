# soy_fish: clear-PETG soy fish lamp shade (vase mode)

A crisp, smooth re-creation of the fish shell from the Soy Fish Lamp, which replicates the real
sushi soy-sauce fish. The cap, the E14 socket holder and the glued thread ring from the original
download are unchanged; only the fish is new.

## What it replicates (measured from the original)
- Body outline and thickness, sampled every 3 mm (`MEASURED` table in `fish.py`).
- Flat fin tabs along the back (+X) and belly (-X): pelvic and anal tabs on the belly, one long back tab.
- 4 rows of scallop scales (5 / 4 / 3 / 2) with crisp upper edges, at the original positions.
- Double gill band with the slightly proud gill cover below it.
- Eye: raised ring + dome. Three slanted pectoral fin bars.
- The プラ recycling mark on the +Y side only (redrawn crisply by `make_mark.py`).
- Two-lobed tail with a centre groove, and the faint line at the tail stem.

## What changed vs. the original fish (all for printing)
| | Original | This version |
|---|---|---|
| Surface | 19.5k triangles, faceted and blurry | 1.3M-triangle smooth surface, crisp details |
| Wall | 2 mm = 2 walls + 15% infill (infill shows through clear PETG) | one continuous 0.7 mm spiral line: no infill, no seam |
| Joint to ring | 2 mm edge butt-glued on the ring's top face | 10 mm neck slides into the ring's bore (glue lap) and seats on a shoulder |
| Tail pinch | up to 60 deg steep | stretched 9.6 mm taller so a single line can follow it |
| Tail lobe | solid lump | same outline from the side views; thinner toward its tip so the top closes |
| Raised edges | vertical steps | shaped to <= ~57 deg (still crisp) |

## Files
- `fish.py`: generator; all parameters at the top (mm), feature positions in the original's coordinates.
  Rebuild: `PYTHONPATH=. uv run python parts/soy_fish/fish.py` -> `out/soy_fish.3mf` / `.stl`.
  Prints vase-mode checks (steepest wall, one loop per layer, bulb clearance).
  Not a build123d `part.py`: the fish is one blended organic surface, generated directly as a mesh.
  Set `MARK_ON = False` for a fish without the recycling mark.
- `make_mark.py` -> `pura_mark.npz`: the recycling mark as a 0.1 mm mask (needs matplotlib + macOS Hiragino font;
  only rerun if you change the mark).
- `make_project.py` -> `out/soy_fish_project.3mf`: a Bambu Studio project with all print settings embedded
  (run after `fish.py`: `uv run python parts/soy_fish/make_project.py`; needs Bambu Studio installed).
- `bambu/process_soy_fish_vase.json`, `bambu/filament_clear_petg_vase.json`: the same settings as reusable
  presets (File > Import > Import Configs...), if you want them in your preset list.
- `out/soy_fish.3mf` / `.stl` are plain meshes: they carry **no** settings.

## Key dimensions
- Overall: 150.3 x 75.1 x 229.2 mm (original fish: 154 x 74 x 210, plus the new 10 mm neck and the 9.6 mm stretch).
- Neck (goes into ring): OD 37.16 mm, 10 mm long. Ring bore measured 37.76-38.2 mm.
- Clear opening through the neck: ~35.8 mm, so the **bulb must be <= 35 mm across** (E14 C35 candle / small globe).
- Steepest wall: 58.6 deg on a small patch of the belly fin tab where it meets the tail stem; scale edges and
  the eye rim ~56 deg; the head flare ~50-56 deg (as in the original). Fine with 0.7 mm lines at 0.2 mm layers.

## Print (Bambu Lab P2S, 0.4 nozzle, clear PETG)
Open **`out/soy_fish_project.3mf`** and everything below is already set; just slice and print.
Orientation: mouth/neck down on the bed, as exported. No supports.

| Setting | Value | Why |
|---|---|---|
| Spiral vase | ON, smooth spiral ON | one continuous line: no seam, no infill, best clarity |
| Bottom shell layers | **0** | leaves the mouth open (the model is closed at the bottom on purpose) |
| Layer height | 0.2 mm | keeps the crisp scale / eye / fin edges printable as a single wall |
| Line width | 0.7 mm (wall + first layer) | thicker single wall, stronger and glassier |
| Wall speed / accel | 35 mm/s / 2000 | slow + gentle for clear PETG |
| Brim | outer only, 15 mm | the footprint is just the 37 mm neck; it's hidden in the ring, so trim marks don't show |
| Nozzle | 250 C | hotter = better layer fusion = clearer |
| Fan | 15-30%, overhang 50% | low fan keeps PETG clear and layers bonded |
| Flow ratio | 0.98 | (Bambu PETG Translucent default 0.95); bump to ~1.0 if you see gaps between layers |
| Plate | Textured PEI, 70 C | |

Checked with the Bambu Studio 2.9 command-line slicer and these presets: 1147 layers, one unbroken spiral
(no travel moves on the visible body), ~2 h 50 min, ~45 g.

Clarity tips: dry the PETG first (65 C, 4-6 h; wet PETG prints cloudy and stringy). Clean the plate.
If the filament isn't Bambu PETG Translucent, base the filament preset on Generic PETG and keep the
temperature/fan/flow changes.

## Assembly
1. Screw the original ring into the cap and check it runs freely, then unscrew it.
2. Dry-fit the fish neck into the ring: the shoulder should sit on the ring's top edge.
3. Glue with 5-minute epoxy or gel superglue around the neck (fills the ~0.3 mm gap). Keep glue off the
   ring's threads.
4. Fit the E14 socket holder and bulb to the cap as in the original, then gently screw the fish on.

**LED bulbs only** (<= ~5 W). PETG softens around 75-80 C; an incandescent bulb will warp the shell.
