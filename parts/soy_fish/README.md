# soy_fish: clear-PETG soy fish lamp shade (vase mode)

A redesigned fish shell for the Soy Fish Lamp. The cap, the E14 socket holder and the
glued thread ring from the original download are unchanged; only the fish is new.

## What changed vs. the original fish
| | Original | This version |
|---|---|---|
| Surface | 19.5k triangles, visibly faceted | 840k-triangle smooth surface |
| Wall | 2 mm = 2 walls + 15% infill (infill shows through clear PETG) | one continuous 0.7 mm spiral line, no infill, no seam |
| Joint to ring | 2 mm edge butt-glued on the ring's top face | 10 mm neck slides into the ring's bore (glue lap) + seating shoulder |
| Details | soft bumps | overlapping tile scales, raised eye, gill cover, ribbed pectoral fins, back/belly crests, ribbed tail fan, lips |
| Tail | solid 16-18 mm lump | thin ribbed fan (glows nicely) |

## Files
- `fish.py`: generator. All shape parameters are at the top (mm). Rebuild with
  `PYTHONPATH=. uv run python parts/soy_fish/fish.py` -> `out/soy_fish.3mf` / `.stl`.
  It prints vase-mode checks (steepest wall, one loop per layer, bulb clearance).
  Not a build123d `part.py`: the fish is one blended organic surface, generated directly as a mesh.
- `bambu/process_soy_fish_vase.json`, `bambu/filament_clear_petg_vase.json`: Bambu Studio presets
  (File > Import > Import Configs...).

## Key dimensions
- Overall: 140.8 x 75.9 x 234.7 mm (fits the P2S 256 mm cube).
- Neck (goes into ring): OD 37.16 mm, 10 mm long. Ring bore measured 37.76-38.2 mm.
- Clear opening through the neck: ~35.8 mm, so the **bulb must be <= 35 mm across** (E14 C35 candle / small globe).
  The bulb passes through the ring and neck when you screw the fish on.
- Steepest body wall: ~51 deg on a 1 mm^2 spot, everything else <= 50 deg; only the thin fin crests and
  the tail's closing edge (both effectively solid) are steeper.

## Print (Bambu Lab P2S, 0.4 nozzle, clear PETG)
Orientation: mouth/neck down on the bed, as exported. No supports.

| Setting | Value | Why |
|---|---|---|
| Spiral vase | ON, smooth spiral ON | one continuous line: no seam, no infill, best clarity |
| Bottom shell layers | **0** | leaves the mouth open (the model is closed at the bottom on purpose) |
| Layer height | 0.24 mm | fewer layer boundaries = clearer; tested in the slicer |
| Line width | 0.7 mm (wall + first layer) | thicker single wall, stronger and glassier |
| Wall speed / accel | 35 mm/s / 2000 | slow + gentle for clear PETG |
| Brim | outer only, 15 mm | the footprint is just the 37 mm neck; the brim is on the hidden neck, so trimming marks don't show |
| Nozzle | 250 C | hotter = better layer fusion = clearer |
| Fan | 15-30%, overhang 50% | low fan keeps PETG clear and layers bonded |
| Flow ratio | 0.98 | (Bambu PETG Translucent default is 0.95); bump to ~1.0 if you see gaps between layers |
| Plate | Textured PEI, 70 C | |

Sliced with the Bambu Studio 2.9 command-line slicer and these presets: 979 layers, one unbroken spiral
(no travel moves on the visible body), ~2 h 20 min, ~42 g.

Clarity tips: dry the PETG first (65 C, 4-6 h; wet PETG prints cloudy and stringy). Clean the plate.
If the filament isn't Bambu PETG Translucent, base the filament preset on Generic PETG and keep the
temperature/fan/flow changes.

## Assembly
1. Screw the original ring into the cap and check it runs freely, then unscrew it.
2. Dry-fit the fish neck into the ring: the shoulder should sit on the ring's top edge.
3. Glue with 5-minute epoxy or gel superglue around the neck (fills the ~0.3 mm gap). Keep glue off the
   ring's threads.
4. Fit the E14 socket holder and bulb to the cap as in the original, then gently screw the fish on.

**LED bulbs only** (<= ~5 W). PETG softens around 75-80 C; an incandescent bulb will warp the shell.
